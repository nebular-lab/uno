# 計画ドキュメントレビュー

計画ドキュメントをサブエージェントを使って詳細にレビューするスキルです。

## 使い方

```
/review-plan <計画ドキュメントのパス>
```

例:
```
/review-plan doc/claude-plan/my-feature-plan.md
```

## 実行手順

### 1. 引数の確認

**計画ドキュメントのパスが指定されていない場合は、以下のメッセージを表示して作業を中断してください：**

> 計画ドキュメントのパスを指定してください。
>
> 使い方: `/review-plan <計画ドキュメントのパス>`
>
> 例: `/review-plan doc/claude-plan/my-feature-plan.md`

### 2. レビューの実行

計画ドキュメントのパスが指定されている場合、以下の手順でレビューを実行します：

1. **計画ドキュメントを読み込む**
   - 指定されたパスのファイルを Read ツールで読み込む
   - ファイルが存在しない場合はエラーメッセージを表示して中断

2. **サブエージェントでレビューを実行**
   - Task ツールを使用してレビュー用のサブエージェントを起動
   - subagent_type: `general-purpose`
   - 以下のプロンプトでレビューを依頼：

```
以下の計画ドキュメントをレビューしてください。

## レビュー観点

1. **明確性**: 計画の目的、スコープ、成果物が明確に定義されているか
2. **実現可能性**: 技術的に実現可能か、リスクは適切に考慮されているか
3. **完全性**: 必要なステップが網羅されているか、抜け漏れはないか
4. **整合性**: 各ステップ間の依存関係や順序は適切か
5. **テスト可能性**: 成果物の検証方法は明確か

## 重要

- レビュー中に不明な点や曖昧な箇所があれば、必ず質問してください
- 改善提案がある場合は具体的に示してください
- 良い点も指摘してください
```
