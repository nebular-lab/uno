現在のworktreeブランチをmainにマージし、worktreeとブランチを削除します。

## 手順

1. **現在の場所を確認**
   - `pwd` で現在のディレクトリを確認
   - 現在のブランチ名を `git branch --show-current` で取得
   - mainブランチにいる場合は、どのworktreeを終了するか確認

2. **未コミットの変更を確認**
   - `git status` で未コミットの変更がないか確認
   - 変更がある場合はユーザーに確認（コミットするか破棄するか）

3. **mainブランチに移動してマージ**

   ```bash
   cd /Users/daisukehirano/Documents/src/dobon-uno/main
   git merge <ブランチ名>
   ```

4. **マージコンフリクトの処理**
   - コンフリクトが発生した場合は解決を支援
   - 解決後、コミットを完了

5. **worktreeとブランチの削除**

   ```bash
   git worktree remove ../<ブランチ名>
   git branch -d <ブランチ名>
   ```

6. **完了メッセージ**
   - マージが完了したことを報告
   - 現在mainディレクトリにいることを確認

## 注意事項

- mainブランチ自体は削除できません
- マージ前に必ずテストが通ることを確認してください
- リモートにプッシュはしません（必要に応じて手動でプッシュ）
