最新のローカルのmainブランチの変更を現在のブランチに取り込みます。

## 手順

1. **現在の状態を確認**
   - `git branch --show-current` で現在のブランチを確認
   - mainブランチにいる場合はエラー（mainにはマージできない）

2. **未コミットの変更を確認**
   - `git status` で未コミットの変更がないか確認
   - 変更がある場合はユーザーに確認（先にコミットするか、stashするか）

3. **mainの変更を取り込む**

   ```bash
   git merge main
   ```

4. **マージコンフリクトの処理**
   - コンフリクトが発生した場合は、マージを取り消す：
     ```bash
     git merge --abort
     ```
   - ユーザーにコンフリクトが発生したことを伝える
   - 手動で解決するためのコマンドを案内：
     ```
     git merge main
     # コンフリクトを解決後
     git add .
     git commit
     ```
   - マージは実行せずに終了

5. **完了メッセージ**
   - 取り込まれたコミット数を報告
   - Already up to date の場合はその旨を報告

## 注意事項

- mainブランチでは実行できません
- リモートのmainは取得しません（必要な場合は先に `git fetch origin main` を実行してください）
