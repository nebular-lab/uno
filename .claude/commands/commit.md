変更内容を確認し、適切な粒度に分割してコミットしてください。

## 手順

1. **変更内容の確認**
   - `git status` で変更されたファイルを確認
   - `git diff` で差分を確認

2. **適切な粒度への分割**
   - 変更内容を論理的な単位で分割する
   - 1つのコミットには1つの目的・変更のみを含める
   - 関連しない変更は別々のコミットに分ける

3. **コミットメッセージの作成**
   - 日本語で書く
   - プレフィックス（feat:, fix: など）は付けない
   - 簡潔で明確な説明を書く

4. **コミットの実行**
   - 確認不要でそのまま `git add` と `git commit` を実行
   - コミットメッセージの末尾に以下を追加:
     ```
     Co-Authored-By: Claude Opus 4.5 <noreply@anthropic.com>
     ```

## 注意事項

- `.env` や `credentials.json` などの機密ファイルはコミットしない
