クライアントとサーバーの開発サーバーをバックグラウンドで起動します。

## 引数

$ARGUMENTS に以下の形式で指定されます：

```
[ブランチ名]
```

- **ブランチ名**: オプション。指定がない場合は現在のディレクトリのworktreeを使用

例:

- （引数なし） → 現在いるworktreeでdevサーバーを起動
- `feat-a` → feat-aのworktreeでdevサーバーを起動

## 手順

1. **対象ディレクトリの決定**
   - $ARGUMENTS が指定されている場合: `/Users/daisukehirano/Documents/src/dobon-uno/<ブランチ名>`
   - 指定がない場合: `pwd` で現在のディレクトリを使用
   - ディレクトリが存在しない場合はエラー

2. **sharedパッケージのビルド**
   - サーバー起動前にsharedパッケージをビルド：
     ```bash
     cd <対象ディレクトリ>/packages/shared && pnpm build
     ```

3. **devサーバーの起動**
   - サーバーとクライアントのdevサーバーをバックグラウンドで起動：
     ```bash
     cd <対象ディレクトリ>/apps/server && pnpm dev
     ```
     ```bash
     cd <対象ディレクトリ>/apps/client && pnpm dev
     ```
   - 両方ともバックグラウンドで実行する

4. **起動確認**
   - 数秒待ってから出力を確認
   - 起動に成功したかどうかを報告

5. **完了メッセージ**
   - サーバーとクライアントが起動したことを報告
   - アクセスURLを案内

## 注意事項

- .envファイルが存在しない場合、デフォルトのポート設定で起動されます
- 同じポートで既にサーバーが起動している場合はエラーになります
- バックグラウンドタスクはセッション終了時に自動的に停止します
