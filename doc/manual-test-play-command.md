# PlayCardCommand 動作確認手順書

PlayCardCommand（カードを出す）の各種動作を手動で確認するためのテスト手順。

---

## 準備

### 1. デバッグ用コード追加（一時的）

`apps/client/src/atoms/connectionAtoms.ts` の2箇所に以下を追加する。

```typescript
// createRoomAtom内（239行目付近）
set(gameStateAtom, { status: "connected", room });
(window as any).__debugRoom = room; // ← 追加

// joinRoomAtom内（286行目付近）
set(gameStateAtom, { status: "connected", room });
(window as any).__debugRoom = room; // ← 追加
```

### 2. サーバー・クライアント起動

```bash
pnpm dev
```

### 3. ブラウザでルームを作成

1. ブラウザを3ウィンドウ開く（P1, P2, P3）
2. P1: `http://localhost:5173` でルームを作成（P1がオーナー）
3. P2, P3: ルームに参加
4. P2, P3: 準備完了にする
5. **P1のブラウザコンソールで後述のデッキセットアップコードを実行**
6. P1: ゲーム開始ボタンを押す

### 4. ヘルパー関数（全シナリオ共通）

P1のブラウザコンソールに以下を貼り付ける。

```javascript
// カード生成ヘルパー
function c(id, color, value, points) {
  return { id, color, value, points };
}

// デッキ構築（3人用）
function buildDeck(firstCard, p1Hand, p2Hand, p3Hand) {
  const padding = [];
  const colors = ["red", "blue", "green", "yellow"];
  for (let i = 0; i < 50; i++) {
    const color = colors[i % 4];
    const value = String(i % 10);
    padding.push(c("pad-" + i, color, value, i % 10));
  }
  const deck = [...padding, firstCard];
  for (let r = 6; r >= 0; r--) {
    deck.push(p3Hand[r]);
    deck.push(p2Hand[r]);
    deck.push(p1Hand[r]);
  }
  return deck;
}

// デッキをセットしてログ出力
function setDeck(firstCard, p1Hand, p2Hand, p3Hand) {
  const deck = buildDeck(firstCard, p1Hand, p2Hand, p3Hand);
  window.__debugRoom.send("__setDeck", deck);
  console.log("デッキセット完了");
  console.log("場札:", firstCard.id, "(points:", firstCard.points + ")");
  console.log("P1手札:", p1Hand.map(c => c.id).join(", "), "| 合計:", p1Hand.reduce((s,c) => s+c.points, 0));
  console.log("P2手札:", p2Hand.map(c => c.id).join(", "), "| 合計:", p2Hand.reduce((s,c) => s+c.points, 0));
  console.log("P3手札:", p3Hand.map(c => c.id).join(", "), "| 合計:", p3Hand.reduce((s,c) => s+c.points, 0));
}

// 手札を直接設定（playing フェーズで使用）
function setHand(sessionId, cards) {
  // __setHandはclient.sessionIdで送る必要があるため、
  // この関数はP1のコンソールからは使えない。
  // 代わりにデッキ構築時に手札を調整する。
  console.log("手札設定:", sessionId, cards.map(c => c.id).join(", "));
}
```
