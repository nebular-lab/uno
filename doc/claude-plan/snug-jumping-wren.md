# チュートリアル: ゲームUI再現デモの実装計画

## Context

チュートリアル動画の点数計算・ドボン・ドボン返しシーンで、実際のゲームUIを使ったアニメーションデモを表示したい。現在はスライド+簡易アニメーションだが、ゲーム画面と同じ見た目のモック画面でプレイの様子を再現する。

## 実現するデモシーン

### 1. 点数計算（scoringPlay）
- スライド表示後、ゲーム画面でプレイヤーが上がる様子を再現
- 誰かがカードを出して手札0枚 → 「上がり！」表示
- 各プレイヤーの上に点数変動を表示（上がった人は+N、それ以外は-N）

### 2. ドボン（dobonPlay）
- 他プレイヤーがスキップ（20点）を場に出す
- 自分の手札合計が20点 → ドボンボタンが光る → ドボン成立
- 「ドボン！」表示 → 点数変動

### 3. ドボン返し（dobonReturnPlay）
- 自分が手札合計100点からドロー4を出す（残り50点）
- 他プレイヤーがドボン宣言
- 自分がドボン返し → 「ドボン返し！」表示 → 点数変動

## 作成するコンポーネント

### MockGameTable（新規: `demo/MockGameTable.tsx`）
ゲーム画面を再現するモックテーブル。Remotionのインラインスタイルで構築。

実際のゲームUIの構造:
- `TableContainer` — 全体のコンテナ（`bg-gradient-to-b from-slate-900 to-slate-800`）
- `Table` — 楕円テーブル（`h-[360px] w-[900px] rounded-full`、ただしチュートリアル画面は960x460程度に収める必要がある）
- `PlayerSeat` × 6 — 楕円に沿って配置（上中央→時計回り）。名前プレート(200x60px rounded-full) + ステータスバッジ(70px丸)
- 場のカード — テーブル中央
- 山札 — テーブル中央左
- `MyHand` — 画面下部に手札表示

チュートリアル用は960x460のデモ領域に収める必要があるため、実際のゲーム画面（1250x592想定）を0.75倍程度に縮小して再現する。

**含まれるもの:**
- 楕円テーブル
- プレイヤー名プレート（簡易版、6席分）
- カード枚数表示（丸バッジ）
- 場のカード
- 山札
- 自分の手札（画面下部）

### MockPlayerSeat（新規: `demo/MockPlayerSeat.tsx`）
プレイヤーシートの簡易版。インラインスタイル。
- 名前 + カード枚数バッジ
- 点数変動表示（±N）
- 「上がり！」「ドボン！」「ドボン返し！」ラベル

### デモシーンコンポーネント（3つ）
- `ScoringPlayDemo.tsx` — 通常上がりの再現
- `DobonPlayDemo.tsx` — 既存を書き換え。ゲームUI使用
- `DobonReturnPlayDemo.tsx` — 既存を書き換え。ゲームUI使用

各デモはRemotionの`useCurrentFrame()`と`interpolate()`でフレームベースのアニメーションを制御。

## シーンごとのアニメーションフロー

### 点数計算デモ
```
フレーム 0-30:   テーブル表示、4人のプレイヤー表示（自分=下中央、手札あり）
フレーム 30-60:  上中央のプレイヤーがカードを出す（手札0枚に）
フレーム 60-90:  「上がり！」ラベル表示
フレーム 90-150: 各プレイヤーの上に点数変動表示
              上がった人: +80（他3人の手札合計）
              自分: -20（自分の手札分）
              他2人: -30, -30
```

### ドボンデモ
```
フレーム 0-30:   テーブル表示、4人、自分の手札表示（合計20点）
フレーム 30-60:  右上プレイヤーがスキップを出す
フレーム 60-90:  自分のドボンボタンがハイライト
フレーム 90-120: 「ドボン！」表示
フレーム 120-180: 点数変動表示
              ドボンした自分: +全員手札合計
              ドボンされた人: -全員手札合計
```

### ドボン返しデモ
```
フレーム 0-30:   テーブル表示、自分の手札（合計100点）
フレーム 30-60:  自分がドロー4を出す（残り50点）
フレーム 60-90:  右上プレイヤーが「ドボン！」
フレーム 90-120: 自分が「ドボン返し！」
フレーム 120-180: 点数変動表示
              ドボン返しした自分: +全員手札合計
              ドボンした人: -全員手札合計
```
